Agent 01
🔍

Prescription Reader Agent

Reads handwritten or printed prescriptions using OCR and AI, then translates into plain local-language.

Tamil Hindi Telugu Kannada
OCR Extraction — Tesseract / Google Vision reads prescription text
Medical Term Parsing — Identifies drug name, dose, frequency, duration
Local Language Translation — AI converts medical English to local language
Example Conversion
Before: "Amoxicillin 500mg TDS × 5 days"
After (Tamil): "காலை, மதியம், இரவு சாப்பாட்டுக்கு பிறகு 1 மாத்திரை, 5 நாள்."
↓
Agent 02
⏰

Medicine Reminder Agent

Generates a personalised schedule and sends automated reminders via Telegram Bot with interactive follow-up buttons.

Auto-Schedule Generation — Creates meal-linked medicine timetable from parsed prescription
Telegram Auto-Message — Bot sends medicine reminder in local language at exact scheduled time
Follow-up Questions — After each reminder, bot asks "Did you take your medicine? ✅ Yes / ❌ No" with inline buttons
Non-compliance Alert — If patient replies "No" or doesn't respond in 30 min, ASHA worker is notified
Voice Call Fallback — Twilio voice call in Tamil/Hindi for patients who miss Telegram
📲 Telegram Bot Conversation
🤖 AAROGYA Bot: "வணக்கம்! உங்கள் BP மாத்திரை எடுக்க நேரமாகிவிட்டது. 💊 Amlodipine 5mg — இப்போது சாப்பிடுங்கள்."

🤖 Follow-up (2 min later): "மாத்திரை சாப்பிட்டீர்களா?"
✅ ஆம், சாப்பிட்டேன் ❌ இல்லை
↓
Agent 03
🧪

Report Explanation Agent

Patient uploads a blood or urine report. AI explains each value in simple, understandable language.

PDF / Image Parsing — Reads test report values automatically
Value Interpretation — Flags abnormal results with context (high/low/normal)
Plain Language Summary — Explains what each result means for the patient's health
AI Explanation
"உங்கள் இரத்தத்தில் ஹீமோகுளோபின் அளவு சற்று குறைவாக உள்ளது. இது மென்மையான இரத்த சோகையை குறிக்கலாம். மருத்துவரிடம் ஆலோசியுங்கள்."
↓
Agent 04
📊

Symptom Monitoring Agent

Checks in daily via Telegram Bot with structured follow-up questions. Tracks symptoms over time and detects worsening trends.

Daily Telegram Check-in — Bot sends structured symptom questions every morning automatically
Inline Follow-up Questions — If patient reports fever, bot asks "How many days? 1 / 2 / 3+" with tap buttons
Voice Input — Patient speaks in Tamil; AI converts via Speech-to-Text and logs symptoms
Symptom Trend Analysis — Detects patterns: fever 3+ days = red alert triggered automatically
Risk Scoring — AI assigns Low / Medium / High risk level per patient after each check-in
📲 Telegram Daily Check-in Flow
🤖 Q1: "வணக்கம்! இன்று காய்ச்சல் இருக்கிறதா?"
✅ இல்லை 🌡️ இருக்கிறது

🤖 Q2 (if fever): "எத்தனை நாள் ஆகிறது?"
1 நாள் 2 நாள் 3+ நாள் 🚨

🤖 Q3: "வலி அளவு எவ்வளவு? (1–10)"
↓
Agent 05
📅

Follow-up Tracker Agent

Tracks all upcoming appointments, tests, vaccinations, and pregnancy checkups. Sends automated reminders.

Appointment Tracking — Next hospital visit, specialist, or lab test date
Vaccination Schedule — Child immunization and adult booster reminders
Maternal Care — ANC visit reminders for pregnant women
72hr Pre-visit Alert — Reminds 3 days and 1 day before each appointment
Reminder Example
"நாளை உங்கள் இரத்த பரிசோதனை நேரம். காலை 8 மணிக்கு PHC க்கு வாருங்கள். வெறும் வயிற்றில் வரவும்."
↓
🚨

Risk Detection → Automatic Doctor Alert

If the Symptom Agent detects worsening condition (fever 3+ days, pain score ≥ 8, or alarming lab values), the system immediately notifies the healthcare worker or doctor — without the patient needing to call anyone.

🌡️ Persistent Fever Detected 💔 BP Spike Alert 📉 Low Hemoglobin Flag 🤱 Pregnancy Emergency
